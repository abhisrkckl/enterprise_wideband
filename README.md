# enterprise_wideband
`ENTERPRISE` extensions for the wideband timing paradigm.

If you find this package useful, please cite
    
    Abhimanyu Susobhanan & Rutger van Haasteren, [Monthly Notices of the Royal Astronomical Society 542(4) pp.2892–2900](https://doi.org/10.1093/mnras/staf1422) (2025)

## Installation
This package can be installed as follows.

    pip install git+https://github.com/abhisrkckl/enterprise_wideband

## Usage
This package follows the `ENTERPRISE` syntax closely.
Please see the example Jupyter notebooks in the `examples/` directory.
